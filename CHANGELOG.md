# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado no [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/) e este projeto adota o [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## Como usar este Changelog:

1. **Padrão de Mensagem**: Cada entrada deve fazer referência à tarefa correspondente do **Jira** (ex: `[KAN-123]`), ao link do Pull Request no **GitHub** (ex: `#45`) e ao autor da contribuição (ex: `@usuario`).
2. **Seções**:
   - `🚀 Novas Funcionalidades (Added)` para novos recursos.
   - `🐛 Correções de Bugs (Fixed)` para correções de bugs.
   - `🔧 Melhorias (Improved)` para melhorias gerais.
   - `🧹 Outros (Chore)` para outras mudanças.
